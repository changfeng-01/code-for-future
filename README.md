# 基于Java的个人健康饮食记录与分析系统

该项目旨在构建一款面向个人的桌面应用，提供每日饮食记录、营养分析、周/月统计与目标管理等能力，采用 Java 17+ 与 JavaFX 实现图形化界面，并使用 CSV 文件保存用户与记录数据。

## 核心功能
- 饮食记录：添加/编辑/删除每日饮食条目，包含时间、食物、类别、摄入量与营养数据。
- 营养分析：计算每日热量、蛋白质、碳水、脂肪的总摄入，生成与目标对比的文字报告。
- 饮食统计：按周/月展示食物类别占比与营养趋势的文本描述。
- 目标设置：为用户配置每日营养目标并实时显示完成进度。
- 数据查询：按日期或日期范围检索历史记录与分析结果。

## 数据存储
- `user.csv`：用户名与每日营养目标。
- `diet_records.csv`：饮食记录（日期、时间、食物、类别、摄入量及营养数据）。
- 通过 Java IO 流读写，适合个人本地使用，无需额外数据库。
